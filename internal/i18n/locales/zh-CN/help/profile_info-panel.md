# 信息面板

单独生成其他图片顶部的玩家信息面板（透明背景的 PNG）。

## 用法
- `/信息面板 <su|ms|all> [u序号]`

## 参数
- `su`：使用抓包数据（Suite），也可以写 `suite`
- `ms`：使用烤森（MySekai）数据，也可以写 `mysekai`
- `all`：同时显示抓包数据和烤森数据，需要两种数据都已上传
- `u序号`：可选，从 1 开始，例如 `u2`；不写时使用默认绑定。未指定区服时按 `/绑定列表` 的全部账号排序，指定区服时按该区服的绑定列表排序

## 示例
- `/信息面板 su`
- `/jp信息面板 ms u2`
- `/信息面板 all`

## 说明
- `su` 需要抓包数据，`ms` 需要烤森数据，`all` 两种都需要，数据都在 Haruki 工具箱上传
- 国服(CN)不支持 `ms` 和 `all`
- 只能查询自己的绑定账号，不支持游戏 UID 或 `@群友`
