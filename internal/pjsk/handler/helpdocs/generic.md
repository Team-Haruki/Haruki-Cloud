# HarukiBot 指令帮助

在任意指令后追加 `-help` 或 `-h` 可以查看对应模块帮助图，例如 `/查曲 -help`。

## 用法
- `<指令> -help`
- `<指令> -h`
- `/help <指令>`

## 参数
- `指令`：要查看帮助的具体指令名或别名。
- `区服前缀`：可用 `/jp` `/cn` `/tw` `/kr` `/en` 指定区服，例如 `/jp查曲 miku`。
- `u1` `u2` 等：账号相关查询可选择绑定列表中的账号。
- `@用户`：群聊中查询对方公开或允许查看的数据。
- `默认区服`：不写区服时优先使用工具箱中的默认绑定账号。

## 示例
- `/查曲 -help`
- `/组卡 -h`
- `/help cr任务`
