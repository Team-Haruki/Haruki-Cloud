# SK 榜线与查榜

## 常用指令
- `/sk线` `/榜线` `/skl`：查询档线。
- `/sk` `/sk查询` `/sk查分`：查询自己、用户、排名或排名段。
- `/时速` `/sks`：查询时速。
- `/日速` `/skds`：查询日速。
- `/查房` `/cf`：查询指定排名附近的玩家；`/cfl` 查询固定常用名次。
- `/查水表` `/csb`：查询玩家当前排名与停车时间。
- `/ptr` `/玩家轨迹`：查询玩家 PT 轨迹。
- `/档线轨迹` `/skt` `/rtr`：查询档线轨迹。
- `/sk预测` `/skp`：查询预测线。
- `/胜率预测` `/5v5预测`：查询 5v5 胜率预测。

## 参数
- 可用排名、排名范围、游戏 UID、`@用户` 或 `u序号`。
- World Link 可加 `wl` 前缀，例如 `/wlsk线 knd`。
- 不写区服时使用默认绑定账号的区服；也可显式 `/cnsk` `/jpsk`。
- 自己当前已不在可记录范围时，`/sk` 会展示最后被记录到的信息并提示已不在记录范围。
