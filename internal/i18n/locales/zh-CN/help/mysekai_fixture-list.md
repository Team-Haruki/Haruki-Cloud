# 烤森家具列表

查看不带个人持有进度的家具图鉴，不需要上传数据。

## 用法
- `/烤森家具列表 [craft|full] [noid]`

## 参数
- 不写参数：显示全部家具，并显示家具 ID
- `craft`：只显示存在制作蓝图的家具，不表示你当前已经获得蓝图或材料足够
- `full`：显示全部家具；与 `craft` 同时出现时，以 `full` 为准
- `noid`：隐藏家具 ID；不写时显示 ID

## 示例
- `/烤森家具列表`
- `/烤森家具列表 craft`
- `/mysekai家具列表 full noid`

## 说明
- 此指令不支持分类或家具名称筛选；按分类查图鉴请用 `/msf full 椅子`
- 查看自己的家具收藏用 `/msf`，查看已获得蓝图用 `/msb`
