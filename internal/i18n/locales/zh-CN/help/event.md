# 查活动

查看单个活动详情；输入筛选条件时列出符合条件的活动。

## 用法
- `/活动 [活动 ID|相对序号|箱活序号|时间关键字]`
- `/活动 <列表筛选…>`

## 参数
### 单个活动
- `活动 ID`：正整数，如 `123` 或 `event123`
- 当前活动：不写时查正在计分的活动，也可以写 `当期`、`今`、`current`、`curr`；活动间歇期会提示没有进行中的活动
- `上期`：最近已结束的活动，也可以写 `上`、`prev`、`perv`
- `下期`：接下来尚未开始的活动，也可以写 `下`、`next`，是否能查看取决于内容开放情况
- 相对序号：`-1` 指当前活动，`-2` 指再前一期，`+1` 指后一期；间歇期优先以下一期为基准，没有下一期时以最近一期为基准
- 箱活序号：角色别名加正数，例如 `mnr1`，查询该角色的第 1 期箱活
### 列表筛选
- 组合规则：不同类别可以组合，用空格分隔；同一类型、团体、属性或年份只写一个值
- 普通活动：`普活`、`马拉松`、`marathon`
- 嘉年华活动：`5v5`、`cheerful`、`carnival`，查询欢乐嘉年华(5v5)活动
- WL 活动：`wl`、`worldlink`、`world`；加期数如 `wl1`、`wl2`、`wl3` 只查该期 WL 活动
- 团体：`ln`、`mmj`、`vbs`、`ws`（或 `wxs`）、`25h`、`vs`，筛选有对应团体加成的活动
- 单团活动：团体前加 `纯`、`仅` 或 `only`，例如 `纯25h`、`only mmj`，要求关联卡牌都属于该团体
- 混团活动：`混活`、`混`、`blend`、`mixed`，不能与团体筛选一起使用
- 属性：`可爱`（`粉`、`cute`）、`帅气`（`蓝`、`cool`）、`纯真`（`绿`、`pure`）、`快乐`（`橙`、`happy`）、`神秘`（`紫`、`mysterious`）
- 角色：角色名或别名，可以写多个；活动关联卡牌必须同时包含这些角色
- 箱活角色：角色后加 `箱` 或 `ban`，例如 `mnr箱`、`mnrban`，只看该角色担任主角的箱活
- 年份：写 `2024年`、`24年`、`今年`、`去年` 或 `前年`；纯数字单独出现时会被当作活动 ID

## 示例
- `/活动`
- `/活动 123`
- `/查活动 mnr1`
- `/活动 下期`
- `/活动 +1`
- `/活动 25h 蓝 2024年`

## 说明
- 单个活动的 ID、序号和时间关键字不要与列表筛选混写
- 单独写 `25` 是活动 ID 25；筛选团体请写 `25h`
- 不需要上传抓包数据
