# 长草组卡

不考虑活动加成，按综合力或实效推荐卡组。需要先在 Haruki 工具箱上传抓包数据（Suite）。

## 用法
- `/长草组卡 [歌曲] [组卡条件…] [u序号]`

## 参数
- 组卡条件：歌曲、Live 类型、目标、演出能量（火）、卡组来源、固定与排除、培养假设、算法，写法和 `/组卡` 相同
- 不能写活动，也不能模拟活动
- `u序号`：可选，选择自己的第几个绑定账号，例如 `u2`；不写时使用默认绑定

## 示例
- `/长草组卡`
- `/长草组卡 当前 单人 综合力`
- `/最强组卡 虾ex 多人 队友实效200`

## 说明
- 发送 `/组卡 -help` 查看全部组卡条件
