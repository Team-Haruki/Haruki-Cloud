# 活动查询

## 常用指令
- `/活动列表` `/events` `/event-list`：输出活动列表。
- `/查活动` `/活动` `/event`：查询活动详情。
- `/冲榜记录` `/活动记录`：查询自己或指定账号的活动记录。
- `/活动规划` `/event-planner`：按目标 PT 或排名生成活动规划图。

## 活动参数
- 活动 ID：`event123` 或 `123`。
- 相对活动：`当前`、`-1`、`next`、`prev`、`上一期`、`下一期`。
- 筛选：团名、角色、年份、活动类型、活动属性、WL 章节等。
- WL 章节：`wl3`、`wl3 miku`、`wl knd`。
- `/活动列表 条件...` 可按年份、团名、角色、活动类型过滤。

## 活动详情与记录
- `/查活动 [活动]`：不写时查询当前或最近活动。
- `/查活动 wl3 miku`：查询 World Link 指定章节。
- `/冲榜记录 [u序号|UID|@用户] [活动]`：查询活动历史记录。
- 账号相关查询需要绑定；查询他人时只能使用公开可见数据。

## 活动规划
- 示例：`/活动规划 pt1000w 当前pt120w 歌 虾ex 龙hd`。
- 目标：`pt1000w`、`1000w`、`t100`、`rank100`。
- 当前进度：`当前pt120w`、`当前排名500`。
- 活动：`event202`、`当前`、`next`、`wl3 mzk`。
- 火数：`5火`、`10火`。
- 队伍：`当前`、`顶配`、`#123 456 789 101 112`。
- 歌曲：`歌 虾ex 龙hd`，可同时比较多首歌。
- WL活动默认按章节单榜规划，加 `总榜` 时按活动总榜规划。
- 不写歌曲时默认计算 `虾 EXPERT`、`龙 HARD` 与 `野车`；不写火数时默认计算 5火和10火。
