# 活动组卡

## 指令
- `/活动组卡`
- `/活动组队`
- `/活动卡组`
- `/活动配队`
- `/组卡`
- `/组队`
- `/配队`
- `/指定属性组卡`
- `/指定属性组队`
- `/指定属性卡组`
- `/指定属性配队`
- `/模拟组卡`
- `/模拟组队`
- `/模拟卡组`
- `/模拟配队`

## 用法
- `/组卡`
- `/组卡 活动或筛选条件`
- `/组卡 歌曲 难度`
- `/组卡 event123 歌曲 难度`
- `/组卡 团名 属性`
- `/组卡 wl章节 角色`

## 参数
- 不写活动时使用当前活动。
- 活动可写纯数字、`event123`、`活动123`。
- 模拟活动可写团名和属性，例如 `mmj 蓝`、`25h 紫`。
- World Link 可写 `wl1 miku`、`event140 wl1`、`event140 miku`。
- 歌曲可写别名加难度，例如 `虾ex`、`龙hd`；未写难度时按组卡服务默认处理。
- 可写 live 类型：`协力`、`单人`、`solo`、`自动`、`auto`。
- 可写目标：`综合力`、`实效`；默认按活动 PT/分数最优。
- 可写体力：`1火` 到 `10火`，不写时按 0 火。
- 可写队伍状态：`当前`、`顶配`、`次顶配`。
- 可写养成参数：`满破`、`满技能`、`已读`、`画布`、`禁用`、`区域道具15级`。
- 可写固定卡牌或角色：`#123 456`、`#miku rin`，必须放在所有参数最后。
- 可写协力限制：`实效200`、`队友综合37w`、`队友实效210`。
- 可写 `歌曲比较` 对比多首歌；不写难度时默认按 `master`。

## 示例
- `/组卡`
- `/组卡 mmj 蓝`
- `/组卡 event123 虾ex`
- `/组卡 龙 hd`
- `/组卡 140 wl1 实效200`
- `/组卡 160 auto #mnr`
- `/组卡 歌曲比较 当前`
