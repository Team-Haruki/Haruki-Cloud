# 查箱

## 用法
- `/查箱 <筛选条件...> [显示控制...]`
- `/卡牌一览 <筛选条件...> [显示控制...]`

## 参数
- 筛选条件：支持 `/卡牌列表` 的角色、团体、稀有度、属性、技能、限定、活动、年份等条件。
- `id`：在图中显示卡牌 ID。
- `box`：显示箱活/活动归属信息。
- `before`：使用特训前卡面；默认使用特训后。
- `属性`、`attr`、`attrs`、`attribute`：按属性分组展示。
- `未持有`、`未拥有`、`unowned`、`missing`、`miss`：只显示自己未持有的卡。
- `u1` `u2` 等：选择自己的第几个绑定账号；不写时使用当前区服默认绑定。
- 区服前缀：可在指令前加 `jp` `cn` `en` `tw` `kr`，例如 `/jp查曲`；不写时使用默认区服。

## 输出
- 以卡面墙形式展示符合条件的卡牌，可用于查箱、补图鉴、确认未持有。

## 示例
- `/查箱 mnr1 id box`
- `/查箱 miku 4星 属性 未持有`
- `/卡面一览 25h 蓝 before`
