# 排名追踪

查看一个固定名次的活动 PT 变化曲线，不追踪该名次上某一位固定玩家。

## 用法
- `/排名追踪 [名次] [活动]`
- `/wl排名追踪 [章节] [名次] [活动]`

## 参数
- 名次：可选，正整数；不写时使用第 1 名，每次只绘制一条名次曲线
### 活动与 WL
- 活动：`event123` 或 `e123` 指定活动 ID；不写时优先使用当前活动，间歇期可能选到下一期，没有下一期时使用最近一期
- 总榜：不写 WL 章节选择时查询活动总榜
- 章节榜：使用 `/wl排名追踪`，角色放在参数开头，例如 `/wl排名追踪 miku`；不写角色时使用最近已开始的章节
- 章节序号：写 `wl2` 选择活动内第 2 章；这里不是第 2 期 WL 活动，与组卡里的 `wl2` 含义不同
- 角色章节：写 `wlmiku`、`wl:miku`、`char:miku` 或 `chara:miku`
- 角色 ID：写 `cid21`、`cid:21`、`char21` 或 `chara21`，按角色 ID 选择章节
- 历史章节：同时写活动 ID，例如 `/wl排名追踪 event123 miku`；未指定活动时须有当前 WL 活动

## 示例
- `/排名追踪 100`
- `/排名追踪 event123 1000`
- `/wl排名追踪 miku 100`

## 说明
- 不支持游戏 UID、`u序号` 或 `@群友`；要追踪玩家请用 `/玩家追踪`
- 不要填写多个名次或范围；当前会只取排序后的第一个名次，不会画多条曲线
- 需要已有历史记录；不需要上传抓包数据
