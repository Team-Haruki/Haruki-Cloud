# 个人资料与账号

## 资料查询
- `/个人信息` `/pjsk profile`：查询公开个人资料。
- `/自定义个人信息` `/cp`：渲染自定义个人信息页，可指定页码。
- `/注册时间`：查询账号注册时间。

## 绑定管理
- `/绑定`：绑定游戏账号。
- `/绑定列表`：查看自己的绑定列表。
- `/切换绑定`：调整绑定顺序。
- `/解绑`：解绑账号。
- `/默认账号`：设置默认绑定账号。
- `/清除默认账号`：清除默认绑定。

## 可见性与设置
- `/隐藏ID` `/展示ID`：控制资料图中的 ID 展示。
- `/隐藏抓包` `/展示抓包`：控制 suite 数据可见性。
- `/隐藏烤森` `/展示烤森`：控制 MySekai 数据可见性。
- `/pjsktz`：设置显示时区。
- `/谱面样式`：设置谱面预览底色。
- `/逮捕难度`：设置逮捕图难度过滤。
- `/上传个人信息背景` `/清空个人信息背景` `/调整个人信息背景`：管理个人资料背景图。
- `/pjsk verify` `/pjsk verify list`：账号验证相关指令。
