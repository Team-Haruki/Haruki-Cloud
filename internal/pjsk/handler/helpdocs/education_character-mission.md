# CR 任务

## 用法
- `/cr任务 <角色>`
- `/cr任务 <角色> all <任务类型>`
- `/角色等级任务 <角色>`
- `/角色等级任务 <角色> all <任务类型>`

## 参数
- `角色`：角色名、昵称或角色 ID。
- `all`：显示指定任务类型的完整档位表，而不是只显示角色等级任务总览。
- `all` 的同义词：`全部`、`全量`、`总表`、`表格`。
- `任务类型`：只在 `all` 模式使用；必须从下面的任务名或别名里选择一个。
- `u1` `u2` 等：选择自己的第几个绑定账号；不写时使用当前区服默认绑定。
- 区服前缀：可在指令前加 `jp` `cn` `en` `tw` `kr`，例如 `/jp查曲`；不写时使用默认区服。

## 基础任务
- `队长次数`：队长 Live 次数。别名：`角色次数`、`队长游玩次数`、`角色游玩次数`、`队长`、`play_live`。查询全量时会同时显示普通任务和 EX 任务。
- `休息室次数`：休息室/控室次数。别名：`休息室`、`控制室`、`waiting_room`。查询全量时会同时显示普通任务和 EX 任务。

## 收集任务
- `服装`：3D 服装收集数量。别名：`衣装`、`服装数量`、`衣装数量`、`collect_costume_3d`。
- `表情`：贴纸/表情收集数量。别名：`贴纸`、`贴纸数量`、`表情数量`、`collect_stamp`。
- `区域对话`：区域对话阅读数。别名：`read_area_talk`。
- `前篇`：卡面剧情前篇阅读数。别名：`前编`、`卡面剧情前篇`、`read_card_episode_first`。
- `后篇`：卡面剧情后篇阅读数。别名：`后编`、`卡面剧情后篇`、`read_card_episode_second`。
- `anvo`：Another Vocal 收集数。别名：`another vocal`、`collect_another_vocal`。
- `卡面`：成员/卡牌收集数量。别名：`图鉴`、`成员`、`collect_member`。
- `台词`：角色语音/台词收集数。别名：`语音`、`collect_character_archive_voice`。

## 区域道具任务
- `单人家具`：单人区域道具升级次数。别名：`单人道具`、`单人家具升级次数`、`area_item_level_up_character`。
- `团家具`：团体区域道具升级次数。别名：`团家具升级次数`、`area_item_level_up_unit`。
- `花树`：属性区域道具升级次数。别名：`树花`、`属性家具`、`属性道具`、`植物`、`属性道具（树&花）升级次数`、`area_item_level_up_reality_world`。

## 技能与专精任务
- `4星技能`：4 星和生日卡技能等级升级次数。别名：`四星技能`、`四星slv`、`4星slv`、`技能等级升级次数（★4&生日卡）`、`skill_level_up_rare`。
- `低星技能`：1 到 3 星卡技能等级升级次数。别名：`低星slv`、`技能等级升级次数（★1~★3）`、`skill_level_up_standard`。
- `4星专精`：4 星和生日卡专精/突破次数。别名：`四星专精`、`四星突破`、`4星突破`、`4星mr`、`四星mr`、`专精等级升级次数（★4&生日卡）`、`master_rank_up_rare`。
- `低星专精`：1 到 3 星卡专精/突破次数。别名：`低星突破`、`低星mr`、`专精等级升级次数（★1~★3）`、`master_rank_up_standard`。

## MySekai 任务
- `ms家具`：MySekai 家具收集数量。别名：`烤森家具`、`mysekai家具数量`、`collect_mysekai_fixture`。
- `ms画布`：MySekai 画布收集数量。别名：`烤森画布`、`mysekai画布数量`、`collect_mysekai_canvas`。
- `ms对话`：MySekai 家具角色对话阅读数。别名：`烤森对话`、`mysekai对话`、`read_mysekai_fixture_unique_character_talk`。

## EX 说明
- `队长次数` 和 `休息室次数` 有普通任务与 EX 任务。
- 写 `all 队长次数` 或 `all 休息室次数` 时会同时输出普通和 EX 的全量档位表。
- `队长次数ex`、`队长次数(EX)`、`角色次数ex` 会识别为 `队长次数`。
- `休息室次数ex`、`休息室次数(EX)` 会识别为 `休息室次数`。

## 输出
- 返回角色等级任务进度；`all` 模式返回指定任务类型的完整明细。

## 示例
- `/cr任务 miku`
- `/cr任务 miku all 队长次数`
- `/cr任务 miku all 休息室`
- `/cr任务 miku 全部 衣装`
- `/角色等级任务 miku 表格 ms对话`
