# 烤森生日材料监听

在群里监听自己的生日派对材料；上传新的烤森（MySekai）数据后，发现所选材料时发送位置。需要先绑定并验证游戏账号。

## 用法
- `/烤森生日监听 [材料…] [时长] [u序号]`
- `/烤森生日取消监听 [u序号]`
- `/ms生日监听 [材料…] [时长] [u序号]`
- `/ms生日取消监听 [u序号]`
- `/mysekai birthday monitor [材料…] [时长] [u序号]`
- `/mysekai birthday unmonitor [u序号]`

## 参数
### 材料
- 不写材料：仅监听钻石；写了材料时只监听本次明确开启的项目，不会自动保留钻石
- `钻石`：也可以写 `diamond`、`ダイヤモンド`
- `夕桐`：也可以写 `yuugiri`、`yugiri`
- `四叶草`：也可以写 `四葉草`、`clover`、`四葉のクローバー`
- `电池`：也可以写 `電池`、`battery`
- `紫水晶`：也可以写 `闪耀石英`、`閃耀石英`、`きらきらクォーツ`、`amethyst`、`quartz`
- 开启材料：材料名直接使用，或在后面连写 `on`、`开启`、`打开`、`启用`，例如 `钻石on`
- 关闭材料：在材料名后连写 `off`、`关闭`、`关`、`禁用`，例如 `电池off`；同一材料以后写的开关为准，最终至少开启一种
### 时长与账号
- `时长`：可选，正整数 1~120，单位为分钟，默认 90；写 `60` 或 `60分钟`，不能写 `1小时`
- `u序号`：可选，从 1 开始，例如 `u2`；不写时使用默认绑定。未指定区服时按 `/绑定列表` 的全部账号排序，指定区服时按该区服的绑定列表排序

## 示例
- `/烤森生日监听`
- `/烤森生日监听 钻石 夕桐 60`
- `/ms生日监听 四叶草 电池off 120分钟 u2`
- `/烤森生日取消监听`
- `/jp烤森生日取消监听 u2`

## 说明
- 只能在群聊使用；数据需通过 Haruki 工具箱上传，监听本身不会登录游戏或自动采集材料
- 再次发送会以本次材料和时长更新监听并重新计时，不写时长会重新使用默认 90 分钟
- 取消时选择同一个绑定账号，只能取消自己在本群创建的监听
- 指令后单独写 `-help` 或 `-h` 查看帮助；不支持 `-r`、`--force` 等普通查询参数
