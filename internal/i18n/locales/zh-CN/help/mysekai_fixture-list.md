# 烤森家具列表

查看不带个人持有进度的家具图鉴，不需要上传数据。

## 用法
- `/烤森家具列表 [craft|full] [分类] [noid]`

## 参数
- 不写参数：显示全部家具，并显示家具 ID
- `craft`：只显示存在制作蓝图的家具，不表示你当前已经获得蓝图或材料足够
- `full`：显示全部家具；与 `craft` 同时出现时，以 `full` 为准
- 分类：可选，一次一个，写法和 `/msf` 的分类相同，例如 `椅子`、`画布`
- `noid`：隐藏家具 ID；不写时显示 ID

## 示例
- `/烤森家具列表`
- `/烤森家具列表 craft`
- `/烤森家具列表 craft 椅子`
- `/mysekai家具列表 full noid`

## 说明
- 不支持按家具名称筛选
- 查看自己的家具收藏用 `/msf`，查看已获得蓝图用 `/msb`，查看还能拿首次制作经验的家具用 `/烤森首次制作`
