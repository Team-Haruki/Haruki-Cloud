# 清除默认绑定

清除全局或指定区服的默认绑定，不会解绑游戏账号。

## 用法
- `/清除默认绑定 [u序号|游戏 UID]`

## 参数
- 不写账号：清除当前范围的默认绑定
- `u序号`：可选，从 1 开始；仅当选中的账号是当前范围的默认绑定时才清除
- `游戏 UID`：可选，选择自己的一个已绑定账号，作用与 `u序号` 相同

## 示例
- `/清除默认绑定`
- `/jp清除默认绑定`
- `/清除默认绑定 u2`

## 说明
- 未指定区服时操作全局默认绑定；指定区服时只操作该区服的默认绑定
- `u序号` 在未指定区服时按全部绑定排序，指定区服时按该区服的绑定列表排序
- 要重新设置，发送 `/默认绑定 u1`
