# 贴纸

按角色查看贴纸列表，或按贴纸 ID 查询图片。

## 用法
- `/贴纸 [角色] [p 页码]`
- `/贴纸 <贴纸 ID…>`
- `/贴纸 all`

## 参数
- 不写参数：显示全部贴纸列表的第 1 页
- `角色`：可选，角色名或别名，只显示该角色相关贴纸，可与页码组合
- `贴纸 ID`：正整数；只写一个时返回该贴纸原图，写多个时用空格分隔，生成指定贴纸的列表
- 页码：正整数，从 1 开始，写 `p 2`、`page 2` 或 `页 2`，参数与数字间需要空格
- `all`：返回全部分页，也可以写 `全部`、`所有`；单独使用，不与角色或页码混写

## 示例
- `/贴纸`
- `/贴纸 miku p 2`
- `/贴纸 101`
- `/贴纸 101 102`
- `/贴纸 p 2`
- `/贴纸 all`

## 说明
- 贴纸 ID 查询与角色查询是两种不同用法，不要混写
- 不需要上传抓包数据
