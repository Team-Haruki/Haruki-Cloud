# 烤森家具

查看家具详情，或查看带持有标记的家具收藏列表。

## 用法
- `/msf <家具 ID…>`
- `/msf [分类] [u序号]`
- `/msf full [分类]`

## 参数
### 详情与列表
- 家具 ID：正整数，一个或多个，用空格分隔；返回这些家具的详情，不需要上传数据；上传过烤森数据时还会标出还能不能拿首次制作经验
- 不写 ID：显示家具收藏列表，持有过的家具算已获得（任意颜色，分解到 0 件也算；画布看画布持有记录），需要在 Haruki 工具箱上传烤森（MySekai）数据
- `full`：切换为不带持有进度的完整家具列表，不需要上传数据；也可以写 `all`、`全部`
- `u序号`：可选，从 1 开始，例如 `u2`；不写时使用默认绑定。未指定区服时按 `/绑定列表` 的全部账号排序，指定区服时按该区服的绑定列表排序
### 分类筛选
- 分类：可选，一次一个，只用于列表模式；不是任意家具名称或来源关键词
- 大类：`一般`、`小物`、`壁挂`、`展示`、`画布`、`墙`、`地板`、`地毯`、`房子`、`道路`、`栅栏`、`植物`
- 小类：`玩偶`、`彩色砖`、`积木`、`大型`、`床铺`、`桌子`、`椅子`、`沙发`、`架子`、`盆栽`、`家电`、`其他`、`树`、`花`
- 分类别名：支持游戏中的分类原名，以及 `chair`、`table`、`sofa`、`canvas` 等英文写法；所选区服需有该分类

## 示例
- `/msf 101 102`
- `/msf`
- `/msf 椅子 u2`
- `/msf full 椅子`

## 说明
- 家具 ID 可以从 `/烤森家具列表` 获取；不要将 ID 查询与 `full`、分类混写
- 家具详情会显示有关的限时蓝图时间
- `full` 列表不读取个人持有数据；家具详情只在上传过烤森数据时读取，用来标出首次制作经验
- 收藏列表顶部会写出现在可以制作、还能拿首次制作经验的件数；逐件列出请用 `/烤森首次制作`
- 只能查询自己的绑定账号，不支持 `@群友` 或游戏 UID
