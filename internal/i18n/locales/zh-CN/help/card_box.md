# 查箱

把符合条件的卡面排成一览图，可以用来查自己的持有情况。标记持有情况需要抓包数据（Suite）。

## 用法
- `/查箱 [筛选条件…] [显示选项…] [u序号]`

## 参数
- 筛选条件：和 `/卡牌列表` 相同（角色、团体、稀有度、属性、技能、限定类型、年份、活动）
- `id`：在图中显示卡牌 ID
- `box`：显示活动归属
- `before`：使用特训前的卡面
- `属性`：按属性分组
- `未持有`：只显示自己没有的卡，也可以写 `unowned`
- `时间`：只显示自己的卡，按获得时间排列；不能和 `属性`、`未持有` 一起用
- `u序号`：可选，选择自己的第几个绑定账号，例如 `u2`；不写时使用默认绑定

## 示例
- `/查箱 mnr1 id box`
- `/查箱 miku 4星 属性 未持有`
- `/卡牌一览 25h 蓝 before`
