# 烤森商店

## 用法
- `/烤森商店 [类型] [全部]`
- `/msshop [类型] [all]`

## 参数
- 无参数：根据绑定账号上传的数据，仅显示满足通行证和购买限制的每日、每周蓝图。
- `蓝图` / `blueprint`：仅显示每日、每周蓝图。
- `工具` / `tool`：仅显示工具。
- `素材` / `材料` / `material`：仅显示材料。
- `全部` / `full` / `all`：单独使用时显示全部类型，包含已购买、已达限额或当前不能购买的商品；与一种类型组合时只显示该类型，顺序不限。
- 区服前缀：可在指令前加 `jp` `cn` `en` `tw` `kr`，例如 `/jp烤森商店`；不写时使用绑定账号的默认区服。

## 数据与输出
- 需要先绑定账号并上传 Suite 和 MySekai 游戏数据。蓝图列表来自该玩家上传的商店数据；跨日或跨周刷新后，请重新上传，旧数据不会自动生成新一轮商品。
- 蓝图按每日、每周分组，分别标记是否已持有、是否本期已购买。已持有的蓝图仍可能购买，不会仅因持有而隐藏。
- 工具、材料显示售价、获得数量和限购进度；限额读取各区服数据。材料仓库放不下一份兑换数量时也视为不可购买。
- 不显示水晶余额，也不按余额是否足够过滤商品。
- 通行证未生效时，默认提示暂无可购买商品；加“全部”可查看上传数据中的商品及状态。
- 区服没有商店数据时提示“该区服暂未开放烤森商店”；缺少必要用户数据或主数据时提示重新上传或等待同步。

## 示例
- `/烤森商店`
- `/jpmsshop blueprint`
- `/烤森商店 工具 全部`
- `/msshop full material`
