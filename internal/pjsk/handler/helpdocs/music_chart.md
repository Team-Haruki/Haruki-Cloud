# 谱面预览

## 指令
- `/谱面查询`
- `/铺面查询`
- `/谱面预览`
- `/铺面预览`
- `/谱面`
- `/铺面`
- `/查谱面`
- `/查铺面`
- `/查谱`
- `/技能预览`
- `/pjsk chart`

## 用法
- `/谱面预览 曲名或歌曲ID`
- `/查谱面 曲名 难度`
- `/技能预览 曲名 难度`

## 参数
- 支持歌曲名、别名、`music123`、负数索引、活动 ID。
- 自定义谱面建议显式使用日服前缀。
- 歌名里包含 `help` 时会按普通歌名查询；只有单独发送 `-help` 或 `-h` 才进入帮助。

## 示例
- `/查谱面 虾ex`
- `/技能预览 群青master`
- `/谱面预览 Help me, ERINNNNNN!! expert`
