# 全局封禁

## 用法
- `/kill <QQ号> <原因> [天数]`

## 参数
- `QQ号`：要封禁的 QQ，必须为正整数。
- `原因`：必填的单个参数，最长 255 个字符；需要表达多词含义时请不要插入空格。
- `天数`：可选的第三个参数，必须为正整数；不填写时永久封禁。

## 行为
- 封禁该 QQ 使用所有用户功能。
- 同时禁止该 QQ 所拥有的 Bot 登录、校验已有会话及继续请求 Cloud。
- 不允许管理员封禁自己。

## 权限
- 仅 `moderation.admin_qq_ids` 中显式配置的全局管理员可用。

## 示例
- `/kill 123456789 恶意滥用`
- `/kill 123456789 频繁攻击服务 30`
