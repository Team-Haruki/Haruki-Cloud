# 加成组卡

按目标活动加成凑卡组，用于控分。需要先在 Haruki 工具箱上传抓包数据（Suite）。

## 用法
- `/加成组卡 [活动] <目标加成…> [u序号]`

## 参数
- `活动`：可选，`event123` 或 `活动123`；不写时优先使用当前活动，其次使用已开放的下一期活动
- `目标加成`：必填，一个或多个正整数，例如 `120 160`，也可以写 `120加成`、`160%`
- `u序号`：可选，从 1 开始，例如 `u2`；不写时使用默认绑定。未指定区服时按 `/绑定列表` 的全部账号排序，指定区服时按该区服的绑定列表排序

## 示例
- `/加成组卡 120`
- `/加成组卡 event123 120 160`
- `/控分组卡 200%`

## 说明
- 活动 ID 必须带 `event` 或 `活动`，纯数字会作为目标加成
- 按抓包数据中的实际培养状态凑加成，不接受其他组卡指令的歌曲、培养假设和固定卡等条件
