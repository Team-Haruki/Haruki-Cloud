# 查服装

## 用法
- `/查服装 <服装 ID|关键词>`

## 参数
- `服装 ID`：查询单件服装详情。
- `关键词`：非明确 ID 时进入服装列表筛选。
- 分类词：`服装` `饰品` `发型` `男装` `女装` `男饰品` `女饰品` `男发型` `女发型`。
- 角色：角色昵称或角色 ID。
- 分页：`p2`、`每页480`。
- `全部`：显示完整结果。
- 区服前缀：可在指令前加 `jp` `cn` `en` `tw` `kr`，例如 `/jp查曲`；不写时使用默认区服。

## 输出
- 单件服装详情；或在无法唯一定位时返回列表。

## 示例
- `/查服装 33001`
- `/查服装 miku 女装`
