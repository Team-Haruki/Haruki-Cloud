# 活动组卡

## 用法
- `/组卡 [活动/歌曲/组卡参数...]`
- `/活动组卡 [活动/歌曲/组卡参数...]`
- `/模拟组卡 <属性> <团体> [歌曲/组卡参数...]`

## 参数
- 活动：不写时使用当前活动；可写 `event123`、活动 ID、`wl3 miku`、或 `红 25h` 模拟活动。
- `u1` `u2`：选择自己的绑定账号；组卡只读取自己的卡组/快照。
- 歌曲：可写歌曲名、别名或 `music123`；难度可写 `easy` `normal` `hard` `expert` `master` `append` 或 `ez/nm/hd/ex/ma/apd`。
- Live 类型：`多人`/`协力`/`multi`，`单人`/`solo`，`自动`/`auto`。
- 目标：`综合力`/`power` 优先综合力；`实效`/`倍率`/`skill` 优先技能实效。
- 火数：`0火` 到 `10火`，也可写 `boost5`。
- 队友参数：`队友综合25w`、`队友实效200`、`实效200` 可覆盖协力队友假设。
- 算法：`dfs`、`sa`/`ga`、`dfs-ga`、`rl`、`all`。
- 当前队伍：`当前` 使用游戏内当前队伍作为固定队伍。
- 固定卡/角色：`#123 456` 固定卡牌 ID；角色昵称可固定指定角色位置。
- 排除卡：`-1234` 排除指定卡牌 ID。
- 培养假设：`顶配`/`满配`、`次顶配`/`中配`、`满技能`、`满突破`、`剧情已读`、`满画布`。
- 稀有度配置：可给 `1星` `2星` `3星` `4星` `生日` 分别追加培养限制。
- 筛选：`纯ln` `纯mmj` `纯vbs` `纯ws` `纯25h` `纯vs`，以及 `纯红` `纯蓝` 等属性筛选。
- 技能顺序：`技能顺序 1 2 3 4 5` 仅在固定完整队伍或 `当前` 队伍时可用。
- 技能抽取：`技能抽取最高`、`技能抽取最低`、`技能抽取平均` 控制参考技能选择策略。
- 歌曲比较：写 `歌曲比较` 后接多首歌曲，返回同一组卡条件下的歌曲表现对比。
- 区服前缀：可在指令前加 `jp` `cn` `en` `tw` `kr`，例如 `/jp查曲`；不写时使用默认区服。

## 输出
- 返回活动加成、综合力、实效和推荐队伍；活动模式下会尽量考虑活动角色/属性加成。

## 示例
- `/组卡`
- `/活动组卡 event123 虾ex 10火 队友综合25w 队友实效200`
- `/模拟组卡 红 25h 纯25h 顶配 dfs`
