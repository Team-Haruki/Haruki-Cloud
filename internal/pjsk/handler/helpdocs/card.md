# 卡牌查询

## 常用指令
- `/查卡` `/card-detail` `/查牌` `/pjsk card`：查询单张卡或按条件筛选卡牌。
- `/卡牌列表` `/cards` `/card-list`：按筛选条件输出卡牌列表。
- `/卡牌一览` `/查箱` `/卡面一览` `/card-box`：输出卡牌目录或指定角色/活动的一览图。
- `/查卡面` `/卡面` `/卡图` `/pjsk card img`：输出卡面原图。

## 参数
- 单卡：卡牌 ID、角色昵称加负数，例如 `mnr-1` 表示该角色最新一张卡。
- 多卡：角色、团名、稀有度、属性、技能、限定类型、年份、活动 ID 都可以混合。
- 例：`/查卡 25h`、`/查卡 mzk1 4`、`/卡面 190`。

纯数字 `4` 在 `/查卡` 与 `/卡面` 中按卡牌 ID 解析，在 `/卡牌列表` 与 `/卡牌一览` 中按四星筛选解析。
